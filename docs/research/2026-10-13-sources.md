## Thread 0: the host account and the name

Run first, by hand, because house style beats general best practice where the
two disagree.

| # | Source | Opened to find out | What it said |
|---|---|---|---|
| 0.1 | <https://github.com/phagehunter> | Is this an organization or a user account, and what does it publish? | A user account, not an organization. 31 repositories. The pinned six are static HTML sites. |
| 0.2 | <https://github.com/phagehunter/rnaviromeatlas> | House conventions on a representative repository | No license, no description, no topics, no continuous integration. Ships `.nojekyll`, `index.html`, a data file, and one Python script. |
| 0.3 | <https://github.com/phagehunter/biodefense> | Confirm the pattern is not a one-off | Same: no license, no description, no topics, minimal README, `.nojekyll` plus `index.html`. |
| 0.4 | <https://pypi.org/project/sandboxkit/> | Is the working name `sandboxkit` free on the Python package index? | **Taken.** Version 0.1.0, released 2026-09-22, described as a sandbox runner for Linux using namespaces and Landlock. |
| 0.5 | <https://github.com/search?q=sandboxkit&type=repositories> | Is the working name crowded on GitHub? | Ten near-matches. None large. Two of the Python ones are about operating-system sandboxing. |

### What thread 0 settled

**There is no house Python convention to match.** Every existing repository on
the account is a static site. This would be the first Python package there, so
general best practice wins by default rather than by argument.

**The house delivery mechanism is a web page.** Both repositories examined are
GitHub Pages sites. That is the strongest available evidence about how this
author actually reaches an audience, and it is why thread 3 was asked
specifically whether the sealed oracle survives in a browser.

**The working name has to change.** Not because `whybox` is taken, which
is survivable, but because of *what* it is taken by. The existing package is a
tool for sandboxing untrusted code: operating-system isolation. Our "sandbox"
means a closed experimental world. Those two meanings sit one search result
apart, and a reader who finds the wrong one will not realize they have.

## Where threads agreed independently

The threads could not see each other. These three points were reached by more
than one of them, which is why they go at the top of the edit list.

- **Version anything whose change moves a number, and record the version in
  the result.** Threads 1 and 4, from different projects.
- **A canary string in sealed data.** Threads 1 and 4, from different
  precedents.
- **Predicting well is not understanding.** Thread 1 found it as a design
  precedent in a discovery benchmark; thread 3 found it as an empirical result
  in the rule-induction literature. That is our own thesis, confirmed twice by
  searches that did not know about each other.
