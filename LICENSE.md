## Why MIT

The project lead chose to match the license of the original authors' own
repository. That repository, <https://github.com/asr2210/science-sandbox>,
carries the MIT License, Copyright (c) 2025 Ananth Rao. This project therefore
uses MIT as well, with its own copyright line.

Matching was a courtesy rather than an obligation. This project reimplements
the ideas from the paper and copies none of their code, so MIT's condition
about including the copyright notice does not bite here. The attribution
section at the bottom of `LICENSE` credits them anyway, because the framework
is theirs and the scaffolding is not much use without the idea behind it.

## Two things still to decide

**The copyright line reads `phagehunter`**, the GitHub account that publishes
this. A handle is a valid copyright holder, and it keeps a personal address
off a public file. If this work ever needs to be assigned to an institution,
or asserted in a dispute, a legal name is easier to act on than a handle.

**Writing to the authors before publishing has not been done.** The paper says
they want others to build sandboxes in their own fields, so a teaching version
is plausibly of interest to them. That is a courtesy call, not a legal one.

## One condition that is not covered by MIT

Their README states that the Malinois model weights are subject to the
separate boda2 license. Nothing in this repository uses those weights today.
If a damp sandbox is ever built on top of them, it inherits that condition,
and MIT does not override it. This matters because a damp sandbox using a
published model is the obvious second thing to build after the second invented
world.
