# Code of conduct

This project has adopted the **Contributor Covenant, version 3.0**, as its
code of conduct. The full text is published at
<https://www.contributor-covenant.org/version/3/0/code_of_conduct/> and is
incorporated here by reference rather than copied, so that it cannot drift out
of date against the canonical version.

The short version, which is not a substitute for reading it: everyone taking
part is expected to behave in a way that makes other people want to keep
taking part.

## Scope

It applies in this repository, in its issues and pull requests, and anywhere
someone is representing the project.

## Reporting

Two private routes, neither of which puts anything in public:

1. **GitHub's private vulnerability reporting** on this repository, under the
   Security tab. It is labeled for security, and it works for this too: it
   opens a thread only the maintainer can see. Say in the first line that it
   is a conduct report, not a security one.
2. **Email the maintainer** at the address on their GitHub profile.

Reports are handled by the maintainer. Where the maintainer is the subject of
a report, neither route above is appropriate. Raise it instead with a
responsible person at the reporter's own institution, who can take it up
directly.

A report will be acknowledged within a week. The reporter's identity is not
shared with the person reported about without the reporter's agreement.

## A note for students

If you are a student using this for coursework and something here makes you
uncomfortable, you do not need to decide whether it is serious enough to
report. Report it and let someone else weigh it.
